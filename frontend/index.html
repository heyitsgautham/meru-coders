About

The Sanskrit Meter Identification System helps analyze Sanskrit verses and identify their meters (छन्द).

Features

  • Identify meters from Sanskrit text
  • OCR support for images containing Sanskrit text
  • Batch processing of text files
  • Multiple transliteration schemes
  • Fuzzy matching for partial meter identification

How to Use

  1. Choose an input method (Text, Image, or File)
  2. Enter or upload your Sanskrit content
  3. Select analysis mode and output scheme
  4. Click analyze to identify the meter

Technical Details

This application uses advanced algorithms for meter identification, including fuzzy sequence matching and syllable analysis. It supports multiple Indian language scripts through OCR integration.
